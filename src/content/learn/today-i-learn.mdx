그동안 불편했던 점 
1. 글을 임시 보관하고 게시하는데 git으로 관리하다보니 개발할 때 스테이지 올리고 커밋할 때마다 신경써줘야 함 
2. mdx 문법 지원이 안되서 편집기에서 그냥 하얀 플레인 텍스트로 보임 
3. 글 쓰면서 실시간 미리보기가 안됨

<del>잠깐 충동적으로 그냥 개인블로그 말고 티스토리나 velog를 쓸까 생각했다가 관뒀다.</del><br/>
요즘은 옵시디언으로 메모를 한다. 옵시디언에서 플러그인을 사용하면 블로그 글 폴더(content)를 열어서 옵시디언의 실시간 미리보기 기능도 사용하고 git으로 자동으로 올리는 것도 가능하다는 글을 봤다. 
시도해봤는데 미리보기가 깨지는 문제(이미지 경로 때문에)도 있고 content 폴더 내에 불필요한 옵시디언 파일들이 생겨서 지저분해졌다.

결론은? 그냥 확장프로그램으로 편집기 내에서 실시간 미리보기 하면서 쓰기로 했다. MDX 문법 지원 확장프로그램과 markdown 미리보기 확장프로그램을 설치해서 이 문제는 해결했다.

좀 됐지만, 태그 기능도 추가하고 블로그 게시물 폴더(content)에 폴더만 추가하면 자동으로 하위메뉴가 생성되게 자동화했다. 게시물의 mdx의 메타데이터(slug, post 등)만 추가하면 게시물이 알맞게 알아서 생성된다. 이건 나중에 기회가 되면 포스팅 하는걸로...
